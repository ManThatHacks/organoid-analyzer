Shortcuts

VSelect. Click an object to see its numbers; drag to pan.
DDelete: click an object to remove it. Del removes the selected object with any tool.
CAdd circle: press at the centre, drag to the rim.
LAdd freehand: draw around the organoid and let go.
BBrush: grows the object you start on (or the selected one). Starting on empty space with nothing selected makes a new object.
EEraser: removes pixels from any object.
MMerge: click the object to keep, then each object to absorb into it. Esc to start over.
SSplit: drag a line across an object; each side becomes its own object.
[ ]Brush size.
WheelZoom at the cursor. Pan with right / middle drag, or hold Space and drag.
F / WFit the whole image / zoom to the analysed well (dashed yellow circle).
N PNext / previous object in the list, zoomed in, for a systematic review.
H IHide objects (to see the raw image) / hide IDs.
Ctrl+Z / Ctrl+YUndo / redo.
Ctrl+SSave (into the results folder when opened by batch_review.py).
Ctrl+EnterBatch review: save, mark as reviewed and open the next unreviewed image.
Alt+← →Batch review: previous / next image (unsaved edits are saved first).

On export, untouched organoids keep the pipeline's numbering order; gaps left by deletions are closed and new objects are numbered last. organoids.csv gains status, source_id (the pipeline ID) and note columns. Untouched organoids keep the pipeline's exact values. Edited and added ones are measured here, so their rim columns are empty and their axes come from image moments.
